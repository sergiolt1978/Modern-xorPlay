# XorPlay Modern

Modern replacement for the old Xor.Play / sys-play concept for Nintendo Switch CFW.

## Features

- Background music while HOME or an application is active.
- Automatic foreground Application Title ID detection.
- Per-Title-ID playlists.
- Dedicated HOME playlist.
- Default fallback playlist.
- Legacy `xor.play.json` compatibility.
- Legacy `sys-play.txt` compatibility.
- MP3, WAV and OGG playback.
- Streaming decode; tracks are not loaded entirely into RAM.
- Play / pause / resume.
- Previous / next.
- Shuffle.
- Repeat off / all / one.
- Volume.
- Reload configuration.
- Status file for external controllers.
- Simple `xorplay-control.nro` controller application.

## SD layout

```text
sd:/atmosphere/contents/00FF0000A0F1A001/
    exefs.nsp
    flags/
        boot2.flag

sd:/config/xorplay/
    config.ini
    command.txt       # generated by the controller
    status.txt        # generated by the sysmodule

sd:/music/
    default/
        playlist.txt
        track1.mp3
        track2.ogg

    home/
        playlist.txt
        home.mp3

    01007EF00011E000/
        playlist.txt
        zelda.mp3

sd:/switch/
    xorplay-control.nro
```

A playlist line can be:

```text
track1.mp3
track2.ogg
sdmc:/music/my-other-folder/song.wav
```

Relative paths are resolved against the playlist directory.

## Configuration

`sd:/config/xorplay/config.ini`

```ini
[global]
enabled=1
volume=1.00
shuffle=0
repeat=1
poll_ms=500
```

Repeat modes:

- `0` = off
- `1` = repeat all
- `2` = repeat one

## Title ID selection

The sysmodule asks `pmdmnt` for the current application process and then uses `pminfo` to obtain its Program ID.

Priority:

1. `/music/<TITLEID>/playlist.txt`
2. `/music/home/playlist.txt` when there is no application
3. `/music/default/playlist.txt`
4. legacy `/xor.play.json`
5. legacy `/sys-play.txt`

HOME uses:

```text
0100000000001000
```

## Legacy compatibility

### xor.play

The old format is supported:

```json
{
    "0100000000001000": "sdmc:/music/home.mp3",
    "01007EF00011E000": "sdmc:/music/zelda.mp3"
}
```

### sys-play

The old format is also supported:

```text
audio1.mp3
track.wav
music.ogg
```

with files in:

```text
sd:/media/
```

## Build

The project is designed for the current devkitA64/libnx sysmodule template.

```bash
make
```

The build produces:

```text
XorPlay-Modern.zip
```

The GitHub Actions workflow does the same automatically.

## Important

This is intended for a Nintendo Switch running a compatible custom firmware such as Atmosphère. It is not intended for stock firmware.

The sysmodule uses a custom homebrew program ID:

```text
00FF0000A0F1A001
```

If you fork the project, change the ID if you want a different identity.

Third-party decoder sources are fetched by `fetch-deps.sh` from their upstream repositories.
